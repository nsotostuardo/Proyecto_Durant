# Generador de datos

Ejecutable del generador en .exe

Se genera una grilla NxN, definida por el usuario, puede mostrar por pantalla un previsualizacion de los datos, y guardarlos. Los datos se generan aleatoreamente siguiendo algunas reglas preestablecidas.

Entrega un output tipo .csv en formato .txt, sin los nombres de las columnas en el siguiete orden.

```pos_x, pos_y, tipo_terreno, altura, tipo, n_depredadores, n_reina, n_obreras, n_soldados, n_scouts, %_alimento"```
